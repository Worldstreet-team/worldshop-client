# Fonts

`noto-sans-naira.woff2` is a one-glyph subset (U+20A6 ₦) of Noto Sans (variable, wght 300–800), made with
`pyftsubset --unicodes=U+20A6`. Manrope has no Naira sign. Noto Sans © Google LLC, licensed under the
SIL Open Font License 1.1 (https://openfontlicense.org).

`noto-sans-naira-700.ttf` is the same glyph as a static bold TTF instance (fontTools `instancer`, wght 700),
for link-preview images (`next/og` can't read WOFF2 or variable fonts). Same licence.
